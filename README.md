# Six Words, One Story

[![six-words-one-story](https://img.shields.io/badge/make.fun-six--words--one--story-blue)](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410)

A make.fun entry for "Six Words, One Story": one complete story told
in exactly six words.

```sh
python3 main.py
```

It writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`). Python 3.13, standard library only, deterministic.

## The story

> Kept his letters; burned the rest.

Six words, one ended relationship. She kept the letters — the words,
the memory — and burned everything else he left behind. The turn is
the contrast between keeping and burning; what stays unsaid is who he
was, and why only the letters survived.
